## 🚀 Getting Started

Follow these steps to start learning Python.

### 1. Install Python

Download and install Python from the official website:

https://www.python.org/downloads/

### 2. Clone This Repository

Open your terminal and run:

```bash
git clone https://github.com/saifkabbo/Python-For-Beginner.git
```

### 3. Navigate to the Project

```bash
cd Python-For-Beginner
```

### 4. Start Learning

Explore the learning folders and practice the Python examples.

You can use:
- Visual Studio Code
- PyCharm
- Python IDLE
- Any Python-compatible code editor

## 💻 Example Python Code

Here is a simple Python program to get started:
